# AOS 品牌规范

## 品牌原则

AOS (All in One System) 是一个独立的桌面操作系统品牌，不是 Ubuntu 或 Mint 的换皮版本。

## 用户可见界面规范

| 层级 | 要求 |
|------|------|
| 启动画面 | 显示 AOS Logo，无 Ubuntu 标识 |
| 登录界面 | AOS 品牌壁纸 + AOS logo |
| 桌面壁纸 | AOS 自绘壁纸 |
| 任务栏 | 显示 "AOS"，无 Cinnamon logo |
| 启动器 | AOS Launcher（自研）|
| 应用商店 | AOS Store（自研）|
| 设置面板 | AOS Settings（品牌标题栏）|
| 关于系统 | "AOS 1.0，基于 Ubuntu 24.04" |

## 字体规范

- UI 字体：Noto Sans CJK SC（SIL OFL）
- 西文字体：Inter（SIL OFL）
- 终端字体：JetBrains Mono（Apache 2.0）
